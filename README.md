# MOTORA

تطبيق Flutter عربي فاخر لعالم السيارات، مصمم من البداية باتجاه RTL وبهوية مرئية تتكيّف بالكامل مع ذوق المستخدم.

## الإصدار

- الإصدار: `1.0.0`
- رقم البناء: `1`
- المنصة المستهدفة: Android
- الحزمة: `com.motora.motora`

## التجربة

- واجهة رئيسية فاخرة مع اختصارات لتجربة القيادة والصيانة والتمويل.
- معرض لثلاثة طرازات كهربائية مع المواصفات والأسعار.
- مركز خدمات وحالة السيارة والمساعدة على الطريق والشحن.
- حساب مالك وإعدادات عربية كاملة.
- عشرة ثيمات مستقلة تغير لوحة الألوان والخط العربي وشكل البطاقات والأزرار والكثافة البصرية:
  الملكي، الرمال، منتصف الليل، الزمرد، روبي سبورت، اللؤلؤ، ليلة بنفسجية، الجلد الكلاسيكي، آركتيك تك، وغروب.
- عشرة خطوط عربية مضمّنة داخل التطبيق ليعمل المظهر بلا اتصال بالإنترنت.

## البناء محلياً

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug --build-name=1.0.0 --build-number=1
```

ينتج الملف في `build/app/outputs/flutter-apk/app-debug.apk`.

## البناء التلقائي

يبني مسار GitHub Actions ملف APK عند كل رفع إلى `main`، يشغّل التحليل والاختبارات أولاً، ثم:

1. يرفع `MOTORA-v1.0.0-build.1.apk` كـ artifact.
2. ينشئ إصداراً تجريبياً `v1.0.0-build.1` ويرفق ملف APK مباشرة.

[تنزيل APK التجريبي](https://github.com/Alkaraonge/MOTORA/releases/download/v1.0.0-build.1/MOTORA-v1.0.0-build.1.apk)
