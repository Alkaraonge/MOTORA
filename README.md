# زيد للسيارات

تطبيق Flutter عربي لإدارة معرض السيارات. الواجهة جديدة بالكامل، بينما بُنيت الوحدات والحقول التشغيلية بالاعتماد على تطبيق «زيد للسيارات» الإصدار 36.

## الإصدار

- الإصدار: `1.0.38`
- رقم البناء: `2038`
- حزمة المشروع الأصلية: `com.zaidcars.zaid_cars_app`
- حزمة APK المنشور: `com.zaidcars.zaid_cars_app.functional` لتثبيته بجانب الإصدار القديم والنسخة التجريبية المعطوبة
- الحد الأدنى: Android 7 (`API 24`)
- ملف سامسونگ: `arm64-v8a`

## الوحدات

- مخزون السيارات وبيانات الماركة والطراز والسنة واللون والشاصي والمحرك واللوحة.
- المبيعات والمشتريات والعملاء والموردون.
- الديون والدفعات والأقساط مع المبلغ الكلي والمدفوع والمتبقي والاستحقاق.
- عقود البيع وحقول البائع والمشتري والمالك والسيارة والمبلغ والملاحظات.
- الصندوق والمصاريف وأرباح السيارات والموظفون والمهام.
- التقارير الأسبوعية والشهرية، محول العملات، النسخ الاحتياطي وتصدير Excel.
- حفظ محلي دائم لكل الوحدات مع الإضافة والتعديل والحذف والبحث.
- البيع الآجل ينشئ ديناً تلقائياً، والدفعات تحدّث المتبقي، والشراء يضيف السيارة للمخزون.
- نسخة احتياطية JSON قابلة للاستعادة وتصدير CSV متوافق مع Excel.
- عشرة ثيمات تغيّر الألوان والخطوط والبطاقات والأزرار بالكامل.
- خطوط عربية كاملة مضمّنة لمنع انفصال الحروف أو تشوهها.

## التحقق والبناء

```bash
flutter pub get
flutter analyze
flutter test
ORG_GRADLE_PROJECT_customApplicationId=com.zaidcars.zaid_cars_app.functional \
flutter build apk --release --target-platform android-arm64 \
  --build-name=1.0.38 --build-number=2038
```

يبني GitHub Actions ملف APK، ويرفعه كـ artifact ثم ينشره في Release تجريبي.

[تنزيل APK لسامسونگ](https://github.com/Alkaraonge/MOTORA/releases/download/v1.0.38-build.2038/Zaid-Cars-v1.0.38-build.2038-Samsung.apk)
