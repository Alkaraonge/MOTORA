# DBC Independent — الإصدار التجريبي 1.1.0

**مشروع مستقل لتجريب واجهة مستوحاة من شرح تطبيق KemetDBC**. ليس التطبيق الأصلي وليس نسخة وظيفية 100%، ولا يتصل بسيارة أو ينفذ أوامر ADB أو نظام مكابح أو كاميرات المصنع.

## لماذا هذه النسخة؟

- نسخة DBC Companion 1.0.0 السابقة أبلغ المستخدم بأنها تنهار على سامسونج.
- تمت مراجعة أربعة فيديوهات قدمها المستخدم، وعينة KemetDBC APK 2.0.1، ومصفوفة 23 فئة من الوظائف.
- الواجهة الحالية أفقية: 4 أعمدة × 4 صفوف، القائمة الجانبية، الطاقة، الرحلات، الصيانة، المودم، ADB، الإعدادات.
- تمييز واضح بين **DEMO** (قيم توضيحية) و**DISCONNECTED** (بدون بيانات)، مع منع أي تحكم في السيارة.
- المستخدم يستطيع تسجيل رحلة تجريبية (مدة زمنية)، حفظ إعدادات اللغة والثيم، تصدير السجل عبر قائمة المشاركة.

## تشغيل النسخة بدون تثبيت

افتح `app/src/main/assets/index.html` مباشرة في متصفح Chrome (على الهاتف أو الكمبيوتر) لتجربة الصفحات. بعض المتصفحات تقيد نسخ CSV على عنوان `file://`، لكن تطبيق أندرويد يتضمن زر مشاركة النص.

## بناء APK عبر Android Studio

JDK 17، Android SDK 35، وGradle 8.10.2. افتح المجلد في Android Studio وشغل `gradle assembleDebug`، أو استخدم workflow المرفق في GitHub Actions عند وضع المشروع في فرع `kemetdbc-independent` داخل المسار `kemetdbc-independent`.

**لم يتم اختبار APK على سيارة أو جهاز أندرويد حقيقي بعد. لا تعتبر المصدر ملف تثبيت جاهزاً إلا بعد نجاح البناء.**

## ما هو غير مكتمل؟

1. التطابق الحرفي مع كل الشاشات واللغات والانتقالات لم يتحقق؛ بعض الصفحات الظاهرة بالأسماء فقط في الـAPK.
2. جميع قراءات SOC والجهد والحرارة وهمية حتى الوصول إلى واجهات موثقة.
3. وظائف نظام السلامة والفرامل/الكاميرا/ADB وأوامر النظام/النوافذ غير مفعّلة.
4. لا يوجد استنساخ خادم ترخيص Kemet ولا أي تجاوز للتفعيل الأصلي.
5. اختبارات على السيارة الفعلية لم تحدث بعد.

اقرأ `docs/apk_analysis.md` و`docs/visual_review.md` و`docs/feature_matrix.csv` لمعرفة الأساس ونقاط الثقة.
