# DBC Independent 1.3.0 — واجهة عربية تجريبية مستقلة

هذا تطبيق **تجريبي مستقل** مستوحى من واجهات KemetDBC، وليس البرنامج الأصلي، ولا يملك اتصالاً مباشراً بسيارة BYD. لا يعدّل الكبح الطارئ أو المودم أو النوافذ أو التحديثات أو نظام أندرويد.

## الإصلاحات في 1.3.0

- العربية الافتراضية مع اتجاه RTL في الواجهات والقائمة الجانبية وبطاقات الرئيسية والجداول.
- تعريب الواجهات والرسائل والأزرار والتبويبات وحقول البحث ووصف الإعدادات، مع خيار إنجليزي محفوظ.
- 17 صفحة تجريبية، وتبويبان للرحلات، وثلاثة تبويبات للمودم (نظرة عامة وeSIM والاتصال السحابي).
- زر رجوع حقيقي وسجل تنقل داخل التطبيق مع دعم زر رجوع أندرويد.
- الاحتفاظ بترتيب بطاقات الرئيسية وباختيارات التطبيقات التجريبية وتفضيلات الشاشة.
- حفظ السجل التجريبي عند انتهاء الرحلة وليس عند بدايتها، مع احترام خيار الحفظ التلقائي.
- تصدير السجل والنصوص عبر مشاركة أندرويد عند التشغيل داخل التطبيق، وعبر تنزيل المتصفح في HTML.
- منع إدخال HTML من حقل البحث إلى قيمة HTML وفرض حدود قيم إدخال الأسعار وسعة البطارية.
- تصحيح عرض ADB والتجوال إلى «غير متصل/غير متاح» بدلاً من الادعاء بوجود اتصال.
- تصحيح التاريخ على بطاقة اليوم وإلغاء الحدث المستقبلي القديم المنسوخ من الفيديو.
- تفعيل شكل المظهر النهاري وحجم الفقاعة عند اختيار الإعدادات، والوضع التجريبي بلا بيانات حقيقية.

## ما هو غير منفذ

لا يقرأ SOC/BMS ولا سرعة أو حالة حقيقية من سيارة، ولا ينفذ أوامر OTA، AEB، ADB، eSIM، النوافذ، أو الكاميرات. بعض الصفحات التوضيحية مستندة إلى أسماء الموارد في APK، وتفاصيلها الأصلية غير مؤكدة. لا ينبغي استخدام هذا التطبيق كأداة سلامة أو تشخيص للمركبة.

## البناء

تحت `app/src/main/assets/index.html` يوجد كود الواجهة. Activity من أندرويد تعرض الملف محلياً. المشروع يُبنى في GitHub Actions باستخدام Java 17 وGradle 8.10.2 وAndroid SDK 35 عبر `gradle assembleDebug`، قبل ذلك يجري `python3 scripts/validate_ui.py`.

للاختبار البصري التفاعلي محلياً (على جهاز يحتوي Playwright وChromium): `python3 test_arabic.py` مع تعديل مسار الملف إذا لزم الأمر.

لا يعتبر نجاح البناء اختباراً فعلياً للتثبيت على هاتف سامسونگ أو شاشة BYD. يجب فحص التثبيت والفتح يدوياً بصورة آمنة.
