# اختبار DBC Independent 1.3.0

حالة: نسخة واجهات تجريبية قابلة للبناء، وليست KemetDBC الأصلي.

## أعمال تم تنفيذها

| المكون | التغيير | اختبار محلي |
|---|---|---|
| 17 شاشة | تعريب النصوص والأزرار والقوائم والرسائل | فتح كل شاشة دون أخطاء JavaScript |
| الرحلات | تبويب السجل والإعدادات؛ حفظ عند إنهاء الرحلة | نجح في Playwright |
| الشبكات | نظرة عامة وeSIM والاتصال السحابي | نجحت التبويبات الثلاثة |
| إعدادات اللغة | تبديل العربية/الإنجليزية ودعم RTL/LTR | نجح |
| الإعدادات | حالة العناصر العائمة والمظهر | نجح التبديل |
| البطاقات | تبديل موضع بطاقتين مع حفظ التسلسل | نجح |
| التطبيقات التجريبية | البحث والاختيار وحفظها | نجح |
| التنقل | الرجوع للقسم السابق وزر أندرويد | اختبار الويب نجح |
| تصدير البيانات | مشاركة عبر جسر Android، تنزيل HTML | مسار جسر Android لم يُختبر على جهاز فعلي |
| شيفرة JS | فحص بناء Node syntax | نجح |

## قيود موثقة

- قيم الطاقة والرحلات التاريخية من فيديوهات مرجعية؛ ليست بيانات مركبة حية.
- وظائف النظام الحساسة تبقى معطلة؛ لا توجد واجهات مصنع BYD معتمدة.
- لا يمكن اعتبار التطبيق مطابقاً بالكامل للأصل، خصوصاً خدمات Android الخلفية ووظائف Head Unit.
- الاختبارات المحلية لم تُجرَ على هاتف فعلي.
